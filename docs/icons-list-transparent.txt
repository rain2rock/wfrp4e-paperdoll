ТРЕБОВАНИЯ
═══════════════════════════════════════════════════════════════════════

Фон:         ПОЛНОСТЬЮ ПРОЗРАЧНЫЙ (альфа-канал), без пергамента и подложки
Рамка:       НЕТ. Рамку рисует сам модуль поверх иконки, и она РАЗНАЯ
             по типу записи: у состояния одна, у травмы другая, у крита,
             болезни и мутации - свои. Впечатанная рамка даст двойную.
Поля:        ~8% пустоты от края, чтобы рисунок не упирался в рамку модуля
Контур:      предмет должен читаться и на светлом пергаменте, и на тёмном
             фоне - держать тёмную обводку и не делать светлые силуэты без контура
Размер:      192 x 192 px, PNG с альфой

Образцы для сверки стиля (существующий арт):
  assets/icons/talents/hardy.png
  assets/icons/equipment/weapons/sword-hand-weapon.png

Общий стиль (одинаков для обоих списков):
  Размер:      192 x 192 px, PNG
  Стиль:       монохром в тёплой сепии, почти без цвета; рисунок пером /
               гравюра XVI века, тонкая штриховка, мягкая тень под объектом
  Композиция:  один предмет по центру, крупно, под лёгким наклоном
  Настроение:  мрачное низкое фэнтези Warhammer Fantasy - потёртость,
               грязь, следы использования; без ярких цветов и свечения
