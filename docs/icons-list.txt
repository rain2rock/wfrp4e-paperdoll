ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ (одинаковы для всех файлов)
═══════════════════════════════════════════════════════════════════════

Размер:      192 x 192 px
Формат:      PNG, БЕЗ прозрачности (все пиксели непрозрачные)
Рамка:       впечатана в сам файл - тёмная окантовка с золотыми уголками
Фон:         светло-серый пергамент с лёгкой зернистостью
Стиль:       монохром в тёплой сепии, почти без цвета; рисунок пером /
             гравюра XVI века, тонкая штриховка, мягкая тень под объектом
Композиция:  один предмет по центру, крупно, под лёгким наклоном,
             поля ~10% от края рамки
Настроение:  мрачное низкое фэнтези Warhammer Fantasy - потёртость,
             грязь, следы использования; без ярких цветов и свечения

Образцы для сверки стиля:
  assets/icons/talents/hardy.png
  assets/icons/equipment/weapons/sword-hand-weapon.png
  assets/icons/injuries/broken-leg.png

После добавления файлов в wfrp4e-paperdoll выполнить:
  node tools/build-icon-index.mjs
