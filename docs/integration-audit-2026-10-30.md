### Отдых

- Обычный отдых вызывает `actor.setupSkill(Endurance, {rest:true, tb, skipTargets:true})`; при отсутствии метода навыка используется `setupCharacteristic("t", context)`.
- Сложность +20 задаёт система по флагу `rest`; модуль не прибавляет её второй раз.
- Системная карточка и её перебросы принадлежат WFRP4e. Базовое лечение применяется из Apply Healing, а не немедленно кодом Paperdoll.
- За выбранный полный день покоя фиксированный дополнительный БВ начисляется отдельно после принятого системного броска. При отмене и ошибке бонус не выдаётся. Переброс системной карточки не запускает повторное начисление бонуса дня.
- Сохранена формула `max(0, БВ + УУ) + БВ`: её нельзя заменить на `max(0, 2*БВ + УУ)`.
- Пока системный диалог открыт, повторное нажатие не начинает второй отдых.
- Простой d100 остался только для окружений без системных методов, включая мок.
- В запасном разборе d100 автоматический успех 01-05 даёт минимум +1 УУ, автоматический провал 96-100 - минимум -1 УУ, как в изученной версии системы. Пользовательские правила и остальные подробности настоящих проверок считает система.

### Системные броски

- При ошибке системного каста, молитвы, оружия, навыка или характеристики больше не происходит дополнительного самодельного броска.
- Отмена системного диалога завершает действие.
- Повторный клик на то же заклинание/молитву во время выполнения игнорируется.
- Ошибки объясняются уведомлениями на русском и английском.

### Расходники

- Повторный клик по предмету во время его использования не списывает вторую дозу и не создаёт второй эффект.
- Пассивные эффекты (`transfer` и системный тип `document`) не копируются заново на персонажа при употреблении.
- Ошибка публикации карточки или создания эффекта останавливает дальнейшее списание количества; блокировка освобождается.
- Это не транзакция сервера: если часть действий уже успела выполниться до следующей ошибки, уведомление просит проверить количество и эффекты. Одновременное использование разными клиентами отдельно не проверялось.

### Русские цели магии

- Исправлены границы слов для «Вы», «Себя», «На себя», «По описанию», «СВБ», «Бонус Силы Воли».
- `WPB targets` теперь использует бонус Силы Воли.
- `You or Touch` больше не считается отсутствием цели.
- Счётчик проверок магии вычисляется из действительно выполненных проверок, а не задаётся константой.

### Надёжность QA

- `qa.mjs` и `magicchk.mjs` завершаются с ошибкой при провале проверок или ошибках страницы.
- В `run-all.sh` включён `pipefail`, удалены обрезающие вывод конвейеры.
- Добавлен `nativechk.mjs`: проверяет границу системного API на заглушках, ошибки/отмену, защиту повторных действий, лечение и подбор иконок.
- Проверено на намеренно испорченных временных моках: неправильные УУ и неправильный бой без оружия приводят к ненулевому коду завершения. Рабочие файлы для этих экспериментов не портились.
- Зависимости используются из уже установленной основной копии через локальную ссылку; `.gitignore` исключает и такую ссылку.
