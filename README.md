# WFRP4e Paperdoll

Окно снаряжения в стиле WoW для системы WFRP4e (Foundry V13/V14, система 9.x).

## Установка

1. Распакуй архив в папку данных Foundry: `Data/modules/wfrp4e-paperdoll/`
   (внутри должен сразу лежать `module.json`, а не ещё одна папка).
2. Перезапусти Foundry (или вернись в меню Setup).
3. Зайди в мир → «Настройки игры» → «Управление модулями» → включи «WFRP4e Paperdoll».

## Как пользоваться

- В шапке листа персонажа появится иконка щита с человечком - она открывает куколку.
- Перетащи предмет из сумки в слот - надеть. Из слота в сумку - снять.
- Двойной клик - надеть в подходящий слот / снять.
- Клик по слоту (и по слоту сумки) открывает список: что сейчас надето (крестик - снять) и всё, что можно надеть в этот слот. Клик по предмету в списке - надеть.
- В списке быстрой смены предметы отсортированы по силе, лучший помечен **BIS**, справа разница с надетым (+2 AP, -1 урона).
- Под предметами в списке - пометки ограничений по правилам 4e:
  «Нет навыка» для стрелкового без специализации и «Против обетов» (Ульрик: порох, шлемы, арбалеты) - такие вещи не участвуют в BIS;
  «Без навыка: без достоинств», «-20 неосновной рукой», «-1 к сотворению (УУ)» для магов в броне - это штрафы, они снижают оценку.
  Профиль ограничений модуль собирает сам из навыков, талантов и бога персонажа.
- Таланты в оценке оружия: Могучий удар и Точный выстрел прибавляются к урону, Верный выстрел ценится выше для стрелкового,
  Амбидекстр уменьшает штраф неосновной руки (-20 -> -10 -> 0), Двойная атака повышает ценность оружия во второй руке.
  Ближний бой (парирующее) снимает штраф неосновной руки только в защите. Ярость показывается в тултипе, в BIS не входит.
  Какие таланты учтены, видно в шапке списка быстрой смены.
- В тултипах сокращения расшифрованы: «6 ЗК» -> «6 золотых крон (ЗК)», «-2 УУ» -> «-2 уровня успеха (УУ)».
- В списке быстрой смены внизу есть «Снять всё» - оставить слот пустым одним кликом.
- Поверх модели лента эффектов, как баффы и дебаффы в WoW:
  состояния (ЛКМ снимает 1 уровень), эффекты на персонаже, например от местности (ЛКМ выключает и включает обратно),
  травмы и критические раны со сроком заживления, болезни с инкубацией. ПКМ открывает подробности.
- ПКМ по предмету - открыть его лист.
- Вкладка «Сумка»: три слота для сумок - это разделы списка. Клик по иконке сумки в заголовке раздела открывает список смены
  (BIS по вместимости; сумки, надетые в других слотах, - отдельной группой, выбор меняет слоты местами).
  Свободный слот показан пустым разделом «Сумка N»: нажми на иконку или брось туда сумку, чтобы надеть.
  Вещи в сумке лежат в ячейках как в WoW. Вместимость в WFRP считается в пунктах нагрузки, а не в штуках, поэтому пустые ячейки
  показывают, сколько пунктов ещё влезет: вещь весом 3 занимает одну ячейку с иконкой, но съедает 3 пункта.
  Перетащи вещь в раздел сумки - переложится туда,
  в «При себе» - достанется из сумки. Переполнить сумку нельзя. Снятые сумки с вещами внутри показываются отдельным разделом «не надета».
  Кнопка «Разложить» в разделе «При себе» убирает самые тяжёлые вещи в надетые сумки, пока есть место
  (двуручное и древковое оружие не убирается, вещи с нулевым весом не трогаются). Справа от заголовка - нагрузка от вещей вне сумок.
- Справа от фильтров сумки - кнопка сортировки: как в листе, сначала редкое, сначала обычное, по алфавиту А-Я и Я-А;
  там же вид: ячейки или список с названиями. Фильтр не прячет вещи, а гасит неподходящие.
- Наведи на полоску нагрузки - подсказка, что перегруз делает с персонажем сейчас (скорость, Проворство, усталость), по книге правил.
- Узкое окно: правая панель уходит под куколку.
- Наведи на предмет - тултип с уроном, AP, качествами и изъянами. Цены (самой вещи и строки вроде «Цена ингредиентов» в описании) видит только ГМ.
- Иконки светятся цветом доступности, как редкость в WoW: обычное - белый, дефицит - зелёный, редкое - синий, экзотика - фиолетовый с пульсацией.
- Под портретом две панели статов с выпадашками (физические, разум, бой, защита, судьба; по умолчанию физические и судьба), справа вкладка «Характеристики» со всеми статами по категориям.
- Можно перетаскивать предметы и прямо из обычного листа персонажа в слоты куколки.
- Макрос: `game.modules.get("wfrp4e-paperdoll").api.open(actor)`

## Темы и своя графика

- Оформление в стиле пергамента, как листы WFRP.
- Вся графика интерфейса нарисована своя и лежит в `assets/ui`: силуэты пустых слотов, рамки слотов и редкости,
  рамки эффектов, портрета и карьеры, кнопки, вкладки, панели, фоны и полоски нагрузки.
- Свои иконки предметов, талантов, навыков и травм лежат в `assets/icons` по тем же путям, что и в `wfrp4e-core`.
  Модуль подменяет ими заглушки `wfrp4e-core` (мешок, меч, лук на сотни предметов). Варианты `-fine`, `-flaw`
  и с цифрой берут иконку базового предмета. Выключается настройкой «Свои иконки предметов».
- У самодельных предметов картинка часто чужая (сапоги с картинкой куртки), поэтому сначала смотрим на название:
  сапоги, перчатки, плащ, кольцо, амулет, гримуар и т.д. получают свою иконку. Правила в `scripts/icon-rules.js`.
- Добавил новые иконки в `assets/icons` - запусти `node tools/build-icon-index.mjs`, он обновит список `scripts/icon-index.js`.

## Опции

Шестерёнка справа внизу окна (и настройки модуля), у каждого игрока свои:
учитывать мутации (вкл), учитывать травмы конечностей (вкл), показывать цены предметов (выкл; ГМ видит цены всегда),
звуки интерфейса (вкл; звон монет тихий - четверть громкости интерфейса Foundry).

## Травмы конечностей и протезы

- Потеря кисти, руки, стопы или ноги, перелом и серьёзный разрыв мышц (временно, пока не заживёт) - значок травмы на слоте
  этой конечности и на слоте оружия этой руки, красная подсветка слота. В подсказке - что это значит по книге («Последствия ампутаций»).
- Узнаём травму по картинке wfrp4e-core (не зависит от перевода) или по названию на русском и английском; сторона - из локации травмы.
- В списке смены оружие для руки без кисти помечено «нет кисти» и не участвует в BIS, двуручное - «нужны две руки».
  Щит к культе привязать можно. Перетащить в слот можно что угодно - вдруг ГМ разрешит: значок проблемы останется.
- Протезы надеваются в слот конечности: крюк - на руку (виден и в слоте оружия, в бою - кинжал), деревянная нога - на ногу,
  инженерное чудо - куда угодно, отменяет последствия (значок становится зелёным, травма в ленте бледнеет).
- Shift+ЛКМ по травме в ленте эффектов - удалить её (с подтверждением): зажила, вылечили, ГМ отменил. В списке смены протезы предлагаются только для потерянной конечности.

## Мутации

- Все мутации (телесные и душевные) - в ленте эффектов над моделью, в фиолетовой рамке; в подсказке тип, модификатор и описание.
- Лишняя рука или голова от мутации - дополнительный слот в фиолетовом свечении: «Третья рука» (оружие, щит) в ряду оружия,
  «Вторая голова» (шлем) под головой. До двух лишних рук и двух голов.
- Модуль узнаёт такие мутации по названию («третья рука», «вторая голова», «extra arm», «second head»...). В базовой книге их нет
  (щупальце там - черта-оружие), они бывают в дополнениях и у ГМ, поэтому ГМ кликом по мутации в ленте сам выбирает,
  что она даёт: лишняя рука -> голова -> ничего -> по названию.
- Система WFRP4e о лишних конечностях не знает: вещь в таком слоте просто надета (её AP и лимит экипированного оружия считает система),
  а в какой слот - помнит модуль.

## Шапка

Слева портрет персонажа, справа иконка текущей карьеры (у карьер WFRP своя картинка на каждый уровень), в подсказке класс и карьера.
Под именем деньги персонажа по номиналам: золотые кроны, серебряные шиллинги, медные пенни. В подсказке общая сумма.
ЛКМ по монете - +1, ПКМ - -1, с Shift - по 10. Деньги сразу разменяны: 12 пенни = 1 шиллинг, 20 шиллингов = 1 крона;
если на трату не хватает мелочи, разменивается крупная монета. Курс - в подсказке.
Клик по карьере открывает лист карьеры, по виду или статусу - статью журнала с таким названием (в мире или в компендиумах).

## Правила слотов

- **Броня** - кладётся в любой слот локации, которую защищает, и надевается целиком
  (кольчуга на тело и руки появится сразу во всех своих слотах). Слои брони суммируются, как в правилах.
  Сверху в слоте - самая редкая вещь, при равной редкости слой с наибольшим AP, потом то, что носят поверх: латы, кольчуга, кожа.
  Под доспех можно поддеть только гибкую броню или мягкую кожу (стр. 300): если на одной части тела два жёстких слоя,
  на слоте появится жёлтый значок, а в списке смены - «Не сочетается с …». Надеть всё равно можно - решает ГМ.
- **Штрафы брони к навыкам** - каждый элемент кольчуги или лат даёт -10 к Скрытности (Скр), шлемы и капюшон -10/-20 к Наблюдательности (Набл).
  Достоинство «Практичная» снижает штраф на 10. Сумма видна в статах «Защита», по каждой вещи - в списке смены. Модуль только показывает штрафы, лист не меняет.
- **Оружие** - основная или вторая рука. Как в WoW, то, что мешает, снимается само:
  двуручное снимает всё из рук, одноручное заменяет оружие в своей руке.
  Щит по двойному клику идёт во вторую руку.
  Стрелковое оружие без подходящих боеприпасов в инвентаре (стрелы, болты, пули) помечается значком «Нет боеприпасов».
- **Одежда и аксессуары** - предметы снаряжения типа «Одежда и аксессуары».
- **Сумки** - три слота во вкладке «Сумка». Вместимость берётся из предмета (`system.carries`). По базовой книге:
  кошель 1, наплечная сумка 2, рюкзак 4, мешок 4, большой мешок 6, перемётные сумки 8. Вещи в сумке считаются в нагрузку только весом самой сумки.

Расчёты (AP, нагрузка, лимит оружия) делает сама система - модуль только меняет флаг «надето».

## Пересобрать мок

Проверка мока как пользователь: `node tools/qa-mock.mjs $PWD/mock-qa.html` (см. шапку файла).


```bash
npm install
npm run mock                                   # демо-персонаж + тестовый лут (--loot)
node tools/build-mock.mjs --snapshot tools/snapshot.json --out mock-hugo.html   # свой персонаж
node tools/build-mock.mjs --profile ulric --loot          # проверить ограничения: mage | metal | ulric | duelist
node tools/build-mock.mjs --loot --effects                # тестовые состояния, травма, крит, болезнь
node tools/build-mock.mjs --blank --out mock-blank.html   # чистый персонаж: скромное снаряжение без перевеса и две сумки
node tools/build-mock.mjs --blank --cast                  # плюс переключатель: наёмник и ученица мага

# с настоящими иконками: папка icons из wfrp4e-core и папка icons из Foundry
node tools/build-mock.mjs --snapshot tools/snapshot.json \
  --icons ~/Downloads/icons --icons-core ~/Downloads/icons_core --out mock-hugo.html
```

Иконки подбираются так: сначала путь из самого предмета, потом правила по названию
(`tools/icon-fallbacks.mjs`, сначала wfrp4e-core, потом Foundry). Заглушки wfrp4e-core
(одна картинка на категорию) пропускаются. Мок с иконками не коммитим - это платный контент.

Слепок персонажа снимается скриптом `tools/snapshot-console.js` в консоли Foundry (F12). Файлы `tools/snapshot*.json` и `mock-*.html`
в git не попадают, чтобы не светить инвентарь персонажа в публичном репо.

## Цвета цифр в статах

- Зелёный - характеристика выше обычного: её подняли эффект, талант или правка в листе (модификатор). Подробности в подсказке.
- Красный - снижено или есть урон: модификатор в минус, раны меньше максимума, есть критические раны, штраф к сотворению.
- Обычный цвет - без изменений.
